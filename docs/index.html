reSpotIt

Android app for browsing your saved Spotify album library.

Download APK Source Code

Features

Browse saved albums, filter by genre/artist/year, manage playlists, sync library, queue playback, and more. Works offline with on-device SQLite. No backend required.

Setup

1. Download the latest APK from the releases page.
2. Install on your Android device (enable "Install unknown apps" if needed).
3. Open the app and sign in with your Spotify account.
4. (Optional) Configure your own Spotify credentials in Settings.
